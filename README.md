# the-wild-oasis-backend
this is the wild oasis backend created with supabase downloaded and used localy with docker because supabase server hosting keeps pausing because its not free.

to be able to use it you need docker to be open and to open terminal in this folder and run npx supabase start to host it on localserver.

you need this for both the-wild-oasis and the-wild-oasis-website
